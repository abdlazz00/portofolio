# Project Brief: Website Portofolio Interaktif

## 1. Ikhtisar Proyek (Project Overview)
Proyek ini bertujuan untuk membangun website portofolio interaktif *Single Page Application* (SPA) menggunakan React.js. Website ini dirancang khusus untuk menyoroti keahlian *software engineering* di ekosistem Odoo ERP dan pengembangan Full-Stack (Laravel & React).

## 2. Tujuan (Objectives)
- Memberikan kesan pertama yang profesional kepada rekruter teknis dan manajer IT.
- Mengemas pengalaman kerja internal perusahaan (NDA) ke dalam studi kasus analisis sistem yang solid.
- Memamerkan kode *open-source* dari repositori GitHub (modul Odoo kustom dan aplikasi AI) sebagai bukti nyata kemampuan teknis.
- Menyediakan navigasi yang cepat, responsif, dan langsung pada intinya.

## 3. Target Audiens
- Rekruter IT dan HRD (membutuhkan ringkasan yang jelas dan PDF resume yang mudah diunduh).
- *Tech Lead* / *Senior Developer* (membutuhkan tautan langsung ke repositori GitHub untuk melihat kualitas kode, struktur MVC/Arsitektur, dan logika *database*).

## 4. Ruang Lingkup (Scope of Work)
Website akan terdiri dari satu halaman panjang (*one-page scroll*) dengan bagian-bagian berikut:
1. **Hero Section:** Perkenalan singkat dengan nama, jabatan (*Odoo Programmer & Full-Stack Developer*), dan tombol *Call to Action* (CTA).
2. **About Me (Simple):** Bagian perkenalan diri yang simpel, ringkas, dan tidak bertele-tele. Langsung menyoroti fokus pada Odoo v15-v18 dan arsitektur web.
3. **Experience:** *Timeline* pengalaman profesional dengan fokus pada penyelesaian masalah operasional (misal: modifikasi *role* POS, *bypass state loan management*).
4. **Projects Showcase:** Etalase proyek utama (Rent Management, Library Management, Inilah My Aisisten) dengan kartu bergaya modern.
5. **Skills:** Visualisasi *tech stack* (Odoo, Laravel, React, Nginx, dll) yang dikelompokkan dengan rapi.

## 5. Tumpukan Teknologi (Tech Stack)
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel / Netlify / Jagoan Hosting (Native Nginx config)
